# Candidate pool of 100 text-only, cold-start-safe datasets for AutoModelAdvisor evaluation.
#
# Rationale: diverse text-only datasets spanning domains/knowledge types (medicine, science,
# law, finance, literature, general knowledge, etc.) on which small (~3B param) models can still
# perform competitively. Diversity comes from domain, not modality. Each entry was (1) verified to
# exist on HuggingFace via web search, and (2) checked against the 1,207 dataset nodes in
# artifact_bench/artifact_bench_data/full/node_metadata.json using exact, normalized-suffix, and
# prefix-containment matching, to avoid cold-start contamination (see automodel-advisor-retrieval
# memory for the full contamination-check methodology and known caveats).
#
# NOTE: existence on HuggingFace and absence from the current graph snapshot were verified
# 2026-08-22. Re-run the same check before using this list if the graph or HF datasets change.
#
# SPOT-CHECK (2026-08-22): 22 entries (>=1 per domain) fetched via the HF dataset-card API to
# confirm they're real, non-gated, and match their stated domain/task. One fix applied: the
# original `eli5` entry redirects to `defunct-datasets/eli5` (HF-deprecated) and was replaced
# with `sentence-transformers/eli5`. `tuetschek/multi_woz_v22`'s card mentioned a "deprecated
# builder script" but was confirmed to `load_dataset()` cleanly (datasets==5.0.1, 8437 train
# examples) - false alarm, HF's auto-parquet conversion covers it. The rest of the list was not
# individually re-verified this way - spot-check, not exhaustive.
