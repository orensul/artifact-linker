The Multi-Genre Natural Language Inference (MultiNLI) dataset is a comprehensive collection of 433,000 sentence pairs annotated for textual entailment. It is designed to evaluate natural language understanding models across various genres of spoken and written text. The dataset is monolingual, containing only English language samples, and is categorized under text classification tasks, specifically natural language inference and multi-input text classification. The dataset is divided into three main splits: a training set with 392,702 examples, a validation set with matched genres containing 9,815 examples, and a validation set with mismatched genres containing 9,832 examples. Each data instance includes fields such as promptID, pairID, premise, hypothesis, genre, and a label indicating entailment, neutral, or contradiction. The dataset is released under multiple licenses, including cc-by-3.0, cc-by-sa-3.0, and MIT, allowing for broad usage and modification. The MultiNLI dataset is particularly useful for training and evaluating models on their ability to generalize across different domains, making it a valuable resource for researchers and developers in the field of natural language processing.
