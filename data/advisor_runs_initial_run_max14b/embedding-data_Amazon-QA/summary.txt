The Amazon-QA dataset is a collection of Question and Answer data sourced from Amazon, designed to support tasks such as sentence similarity and paraphrase mining. It is particularly useful for training Sentence Transformers models, which are employed in semantic search and sentence similarity applications. The dataset is structured in English and consists of pairs of query and answer sentences, formatted as dictionaries with keys 'query' and 'pos'. Each entry in the dataset represents a pair of sentences, where 'query' is the question and 'pos' is the corresponding answer. The dataset is available for download and use through the Hugging Face Datasets library, and it can be loaded as a DatasetDict with a training set containing over a million rows. The total size of the dataset is approximately 247 MB. This dataset is intended for researchers and developers working on natural language processing tasks, particularly those focusing on semantic similarity and sentence embedding models. It provides a rich resource for developing and evaluating models that require understanding and processing of question-answer pairs in a commercial context.
