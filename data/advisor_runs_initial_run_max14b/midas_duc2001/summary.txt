The dataset is designed for benchmarking keyphrase extraction and generation techniques from English news articles. It is structured to include several key fields: 'id', which serves as a unique identifier for each document; 'document', a whitespace-separated list of words in the document; 'doc_bio_tags', which are BIO tags for each word indicating whether it is the beginning (B), inside (I), or outside (O) of a keyphrase; 'extractive_keyphrases', a list of keyphrases present in the document; and 'abstractive_keyphrase', a list of keyphrases that are absent but relevant. The dataset is split into a test set containing 308 data points. It is available for use in two main tasks: keyphrase extraction and keyphrase generation. For extraction, the dataset provides the document and BIO tags, while for generation, it includes both extractive and abstractive keyphrases. This dataset is particularly useful for researchers and developers working on natural language processing tasks related to keyphrase identification and generation in news articles. The dataset can be accessed and utilized through the 'datasets' library in Python, facilitating easy integration into various machine learning workflows.
