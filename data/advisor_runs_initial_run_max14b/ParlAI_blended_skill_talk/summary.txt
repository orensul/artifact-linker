The BlendedSkillTalk dataset is a conversational dataset designed to evaluate the ability of conversational agents to blend multiple skills, such as displaying personality, empathy, and knowledge. It contains approximately 7,000 conversations, making it a medium-sized dataset within the range of 1,000 to 10,000 entries. The dataset is monolingual, focusing on English, and was created through crowdsourcing. It is structured to support dialogue generation tasks, with specific task categories including conversational and dialogue-generation. The dataset is divided into three splits: train, validation, and test, with 4,819, 1,009, and 980 examples respectively. Each data instance includes features such as personas, additional context, previous utterances, context, free messages, guided messages, suggestions, guided chosen suggestions, and label candidates. The suggestions feature is further divided into subcategories like convai2, empathetic_dialogues, and wizard_of_wikipedia. The dataset is intended for use in developing and evaluating conversational agents, particularly in scenarios where blending different conversational skills is crucial. The dataset's total size is approximately 99.24 MB, with a download size of 10.89 MB. The dataset's license is currently unknown, and it is part of the original source datasets.
