The Yahoo Answers dataset is a comprehensive collection of text pairs derived from the Yahoo Answers platform, designed for tasks such as feature extraction and sentence similarity. It is a monolingual dataset in English, with a size category between 1 million and 10 million entries. The dataset is structured into four main configurations: 'question-answer-pair', 'title-answer-pair', 'title-question-answer-pair', and 'title-question-pair'. Each configuration contains specific features such as 'question', 'answer', and 'title', all formatted as strings. The dataset is primarily intended for use with Sentence Transformers to train embedding models, making it suitable for natural language processing applications that require understanding and generating text embeddings. The dataset is divided into training splits, with the 'question-answer-pair' configuration containing 681,164 examples, the 'title-answer-pair' configuration having 1,198,260 examples, the 'title-question-answer-pair' configuration comprising 599,417 examples, and the 'title-question-pair' configuration including 659,896 examples. The dataset is available for download, with sizes ranging from approximately 190 MB to 532 MB, depending on the configuration. This dataset is particularly useful for researchers and developers working on machine learning models that require large-scale text data for training and evaluation purposes.
