The EmpatheticDialogues dataset is a collection of conversational data designed to facilitate research in empathetic dialogue generation. It is a monolingual dataset in English, created through crowdsourcing, and is licensed under the Creative Commons Attribution-NonCommercial 4.0 International license. The dataset is categorized under conversational and question-answering tasks, specifically focusing on dialogue generation and open-domain question answering. It contains between 10,000 and 100,000 entries, with specific splits for training, validation, and testing. The training set comprises 76,673 examples, the validation set has 12,030 examples, and the test set includes 10,943 examples. Each data instance includes fields such as conversation ID, utterance index, context, prompt, speaker index, utterance, self-evaluation, and tags. The dataset is intended for use in developing and evaluating models that can engage in empathetic conversations, making it a valuable resource for researchers and developers working on conversational AI systems. The dataset's total size is approximately 25.13 MB, with a download size of 28.02 MB. It is hosted on GitHub, with additional resources and documentation available for users interested in exploring empathetic dialogue systems.
