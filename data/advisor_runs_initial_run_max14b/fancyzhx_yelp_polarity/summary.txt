The YelpPolarity dataset is designed for binary sentiment classification tasks, specifically focusing on the polarity of Yelp reviews. It contains a total of 598,000 samples, with 560,000 allocated for training and 38,000 for testing. The dataset is derived from the Yelp Dataset Challenge 2015 and was curated by Xiang Zhang. It is structured in plain text format, with each entry consisting of a review text and a corresponding label indicating sentiment polarity. The labels are binary, with '1' representing negative sentiment and '2' representing positive sentiment. The dataset is available in two main splits: train and test, with the train split comprising 413,558,837 bytes and the test split comprising 27,962,097 bytes. The total size of the dataset is approximately 441.52 MB. The dataset is intended for use in developing and evaluating text classification models, particularly those that can discern sentiment polarity in textual data. It is a valuable resource for researchers and developers working on natural language processing tasks related to sentiment analysis. The dataset is accessible for download and use in various machine learning frameworks, providing a robust benchmark for sentiment classification models.
