The EnvironmentalClaims dataset is an expert-annotated collection designed to identify real-world environmental claims made by publicly listed companies. It is a monolingual dataset in English, categorized under text classification tasks, specifically binary classification. The dataset comprises text extracted from corporate annual reports, sustainability reports, and earnings call transcripts, focusing on the financial domain. It contains between 1,000 and 10,000 entries, with a total dataset size of 432,514 bytes. The dataset is divided into three splits: a training set with 2,117 examples, a validation set with 265 examples, and a test set with 265 examples. Each entry in the dataset includes a 'text' field, which is a sentence from the source documents, and a 'label' field, indicating whether the sentence is an environmental claim ('1') or not ('0'). The dataset is intended for use in developing models that can automatically detect environmental claims in corporate communications, which can be valuable for researchers and practitioners in finance and sustainability.
