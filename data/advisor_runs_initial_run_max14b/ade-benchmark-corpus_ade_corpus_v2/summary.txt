The Adverse Drug Reaction Data v2 is a comprehensive dataset designed for text classification and token classification tasks, specifically focusing on adverse drug reactions (ADRs). It is a monolingual dataset in English, created by experts, and falls under the size categories of 10K<n<100K, 1K<n<10K, and n<1K. The dataset is divided into three main configurations: Ade_corpus_v2_classification, Ade_corpus_v2_drug_ade_relation, and Ade_corpus_v2_drug_dosage_relation. Each configuration serves a specific purpose. The classification configuration contains text and labels indicating whether a sentence is related to an ADR. The drug-ade relation configuration includes text, drug names, effects, and their respective character indexes within the text. Similarly, the drug-dosage relation configuration provides information on drug names, dosages, and their indexes. The dataset is intended for use in developing models for coreference resolution and fact-checking within the biomedical domain. It is particularly useful for extracting drug-related adverse effects from medical case reports, supporting the development of automated systems for identifying and classifying ADRs. The dataset is available for download, with varying sizes for each configuration, and is primarily used for training purposes.
