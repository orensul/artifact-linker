The CLINC150 dataset is a comprehensive resource designed for intent classification tasks within the domain of text classification. It is a monolingual dataset in English, created through a combination of expert-generated and crowdsourced annotations. The dataset is licensed under the Creative Commons Attribution 3.0 License (cc-by-3.0). It contains between 10,000 and 100,000 examples, making it a medium-sized dataset suitable for training and evaluating machine learning models. The dataset is divided into three configurations: imbalanced, plus, and small, each with varying numbers of examples and bytes. The dataset features two main fields: 'text', which is a string representing the user query, and 'intent', which is a class label indicating the user's intent. There are 151 distinct intent categories, ranging from 'restaurant_reviews' to 'change_volume'. The dataset is split into training, validation, and test sets, with the training set containing the majority of examples. The CLINC150 dataset is particularly useful for developing and testing models that aim to understand and classify user intents in conversational AI systems, chatbots, and virtual assistants.
