Cosmos QA is a comprehensive dataset designed for evaluating machine reading comprehension with a focus on contextual commonsense reasoning. It consists of approximately 35.6K multiple-choice questions that require understanding beyond the explicit text, often involving reasoning about the causes or effects of events described in everyday narratives. The dataset is monolingual, with all content in English, and was created through crowdsourcing. It is structured into three main splits: a training set with 25,262 examples, a validation set with 2,985 examples, and a test set containing 6,963 examples. Each data instance includes a unique identifier, a context passage, a question, four possible answers, and a label indicating the correct answer. The dataset is available under the CC BY 4.0 license, allowing for wide usage in research and development. Cosmos QA is particularly useful for tasks in the domain of natural language processing, specifically for developing and testing models that require an understanding of implicit information and commonsense reasoning. The dataset's size and diversity make it a valuable resource for advancing machine comprehension capabilities.
