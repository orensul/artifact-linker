The RottenTomatoes - MR Movie Review Data is a dataset designed for sentiment classification tasks, specifically binary classification of movie reviews as positive or negative. It contains a total of 10,662 processed sentences sourced from Rotten Tomatoes movie reviews, evenly split between 5,331 positive and 5,331 negative examples. The dataset is monolingual, with all text in English, and was created through crowdsourcing. It is structured into three splits: a training set with 8,530 examples, a validation set with 1,066 examples, and a test set with 1,066 examples. The dataset is relatively small, with a download size of approximately 0.49 MB and a total dataset size of 1.34 MB. Each data instance consists of a 'text' field containing the review sentence and a 'label' field indicating the sentiment, where '0' represents negative and '1' represents positive sentiment. This dataset is intended for use in developing and evaluating sentiment analysis models, providing a benchmark for text classification tasks in the domain of movie reviews. It is particularly useful for researchers and developers working on natural language processing applications related to sentiment analysis.
