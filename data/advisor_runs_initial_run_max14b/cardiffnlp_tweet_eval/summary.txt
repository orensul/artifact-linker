The TweetEval dataset is a comprehensive collection designed for text classification tasks, specifically focusing on tweets. It is monolingual, containing English language data, and is categorized into various configurations such as emoji, emotion, hate, irony, offensive, sentiment, and stance on topics like abortion, atheism, climate, feminism, and Hillary Clinton. The dataset is sourced from extended tweet datasets and is intended for tasks like intent classification, multi-class classification, and sentiment classification. The size of the dataset varies across configurations, with some containing fewer than 1,000 examples and others exceeding 100,000. Each configuration includes features such as text and label, with labels being class labels that vary depending on the configuration. For instance, the emoji configuration includes labels like '❤', '😍', and '😂', while the emotion configuration includes labels like 'anger', 'joy', and 'sadness'. The dataset is divided into training, testing, and validation splits, with varying numbers of examples and byte sizes. The TweetEval dataset is suitable for researchers and developers working on natural language processing tasks related to social media analysis, providing a rich resource for developing and evaluating text classification models.
