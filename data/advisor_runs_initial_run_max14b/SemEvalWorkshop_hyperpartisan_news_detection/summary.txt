The Hyperpartisan News Detection dataset is designed for the task of identifying hyperpartisan news articles, which are characterized by extreme bias towards a particular political stance. The dataset is monolingual, containing English language articles, and is licensed under the Creative Commons Attribution 4.0 International License. It is divided into two configurations: 'byarticle' and 'bypublisher'. The 'byarticle' configuration includes articles labeled through crowdsourcing, focusing on individual articles where consensus on hyperpartisanship was reached. It contains 645 examples with a dataset size of approximately 2.8 MB. The 'bypublisher' configuration is labeled based on the overall bias of the publisher, as determined by sources like BuzzFeed journalists and MediaBiasFactCheck.com. This configuration includes 600,000 training examples and 150,000 validation examples, with a total dataset size of approximately 5.61 GB. The dataset is intended for use in text classification tasks, specifically for detecting bias and hyperpartisanship in news articles. It provides features such as text, title, hyperpartisan label, URL, and publication date, with the 'bypublisher' configuration also including a bias classification label. The dataset is suitable for researchers and developers working on bias detection and related fields.
