The 'movie_recommendation' dataset is designed for evaluating zero-shot recommendation capabilities using language models. It is a monolingual dataset in English, created through a combination of expert-generated annotations and crowdsourcing. The dataset is licensed under Apache 2.0 and is categorized as having fewer than 1,000 entries, making it relatively small in size. It is an original dataset, not derived from other sources, and is intended for tasks such as multiple-choice and question-answering, specifically focusing on movie recommendations. The dataset is part of the BIG-Bench benchmark tasks and is associated with tags like movie-recommendation, collaborative-filtering, movielens, and film. The primary use case for this dataset is to explore how pretrained large language models can function as recommender systems, comparing their performance to traditional matrix factorization methods. This dataset is particularly useful for researchers and developers interested in leveraging language models for recommendation systems, providing a platform to test and refine algorithms in the domain of film recommendations.
