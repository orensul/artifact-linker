The Cornell Movie-Dialogs Corpus is a comprehensive dataset containing fictional conversations extracted from movie scripts. It includes 220,579 conversational exchanges between 10,292 pairs of characters from 617 movies, involving a total of 9,035 characters. The dataset comprises 304,713 utterances and provides rich metadata for both movies and characters. Movie metadata includes genres, release year, IMDB rating, and the number of IMDB votes, while character metadata includes gender information for 3,774 characters and their position in movie credits for 3,321 characters. The dataset is structured with features such as movieID, movieTitle, movieYear, movieIMDBRating, movieNoIMDBVotes, movieGenres, characterID1, characterID2, characterName1, characterName2, and utterance details including text and LineID. The dataset is available in a single 'train' split with 83,097 examples, occupying a download size of 9.92 MB and a generated dataset size of 19.55 MB. This corpus is intended for use in tasks related to natural language processing, dialogue systems, and linguistic style coordination studies, providing a valuable resource for researchers and developers in these domains.
