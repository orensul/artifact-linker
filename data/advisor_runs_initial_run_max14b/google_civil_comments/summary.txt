The Civil Comments dataset is a collection of public comments from the Civil Comments platform, which was active from 2015 to 2017. This dataset includes comments from approximately 50 English-language news sites worldwide. The dataset is designed for toxic comment classification and includes various labels such as toxicity, severe toxicity, obscene, threat, insult, identity attack, and sexual explicit content, all represented as float32 data types. The dataset is divided into three splits: train, validation, and test, with 1,804,874, 97,320, and 97,320 examples respectively. The total size of the dataset is approximately 659 MB, with a download size of 422 MB. The dataset is released under the CC0 1.0 license, allowing for unrestricted use. It was initially created to support research in unintended bias in toxicity classification, as part of a Kaggle challenge. The dataset does not include user IDs, ensuring privacy, and is intended for use in text classification tasks, particularly in identifying and mitigating bias in automated systems. The data is available in a structured format, with each comment accompanied by its respective labels, making it suitable for machine learning applications in natural language processing.
