The BioASQ Task B dataset is a specialized corpus designed for question answering tasks within the biomedical domain. It is curated by biomedical experts and includes various types of questions such as yes/no, factoid, list, and summary questions. However, the primary focus of this dataset is on yes/no questions, specifically Task 7b. Each question in the dataset is associated with a reference text, which consists of multiple sentences extracted from PubMed abstracts, and a corresponding yes/no answer. The dataset is organized into an official train/dev/test split comprising 670 training questions, 75 development questions, and 140 test questions. The dataset is monolingual, available in English, and is licensed under the NLM_LICENSE. It is not publicly accessible, but it is intended for use in biomedical natural language processing tasks, particularly for developing and evaluating neural language models in the context of biomedical question answering. The dataset is part of the larger BioASQ project, which aims to advance the field of biomedical semantic indexing and question answering. More information about the dataset can be found on its homepage.
