The MedQA dataset is a comprehensive resource designed for open-domain question-answering tasks within the medical field. It includes data sourced from medical exams across three regions: the United States, Mainland China, and Taiwan. The dataset is organized into folders corresponding to these regions, with each file formatted in JSONL, where each line represents a data sample as a dictionary. The dataset provides an official random split into training, development, and test sets. Additionally, it includes a '4_options' version for the US and Mainland China, reflecting the multiple-choice format used in the original exams. The dataset also contains extracted medical phrases using the Metamap tool, enhancing its utility for medical language processing tasks. Furthermore, MedQA includes textbooks in both English and simplified Chinese, with the latter available in two formats: sentence-split and paragraph-split. This dataset is particularly valuable for developing and evaluating question-answering systems in the medical domain, offering a rich source of real-world exam questions and relevant textual resources to support machine learning and natural language processing research.
