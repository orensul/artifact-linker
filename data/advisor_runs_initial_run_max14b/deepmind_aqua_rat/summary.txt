The Algebra Question Answering with Rationales (AQUA-RAT) dataset is a comprehensive collection of approximately 100,000 algebraic word problems designed for training models in question-answering tasks. The dataset is monolingual, focusing on English, and is licensed under the Apache 2.0 license. It is structured to support multiple-choice question-answering tasks, where each problem is accompanied by five possible answers, one of which is correct. The dataset includes detailed rationales that explain the step-by-step solution to each problem in natural language, aiding in the development of models that can generate explanations alongside solving the problems. The dataset is divided into three main splits: a training set with 97,467 examples, a validation set with 254 examples, and a test set with 254 examples. Two configurations are available: 'raw' and 'tokenized', each with corresponding data files for train, test, and validation splits. The dataset is intended for use in developing and evaluating models that can understand and solve algebraic problems, providing a robust resource for research in program generation and rationale generation in the domain of educational technology and artificial intelligence.
