The PeerRead dataset is a collection of scientific peer reviews designed to aid researchers in studying peer review processes. It contains over 14,000 paper drafts and their corresponding accept/reject decisions from prestigious conferences such as ACL, NIPS, and ICLR. Additionally, it includes more than 10,000 textual peer reviews written by experts for a subset of these papers. The dataset is structured into two main configurations: 'parsed_pdfs' and 'reviews'. The 'parsed_pdfs' configuration includes metadata such as paper titles, authors, sections, references, and abstracts, while the 'reviews' configuration contains review details like conference names, comments, subjects, and various review scores. The dataset is monolingual, focusing on English, and falls within the size category of 10K to 100K instances. It is intended for use in text classification tasks, particularly in the domain of acceptability classification. The dataset is split into training, testing, and validation sets, with the training set being the largest. The PeerRead dataset is a valuable resource for natural language processing applications and research into the peer review process.
