The Amazon Review Polarity dataset is a large-scale collection of Amazon product reviews, designed for sentiment classification tasks. It contains reviews written in English, spanning a period of 18 years, up to March 2013. The dataset is monolingual and is categorized under the text-classification task, specifically sentiment classification. It is crowdsourced and licensed under Apache 2.0. The dataset is divided into two main splits: a training set with 3,600,000 examples and a test set with 400,000 examples. Each review is labeled as either positive or negative, based on the original star ratings, with scores of 1 and 2 considered negative, and scores of 4 and 5 considered positive. The dataset excludes reviews with a score of 3. Each data instance includes a title, content, and a label indicating the sentiment. The total dataset size is approximately 1.78 GB, with a download size of about 1.15 GB. This dataset is intended for use in developing and evaluating sentiment analysis models, providing a benchmark for text classification algorithms.
