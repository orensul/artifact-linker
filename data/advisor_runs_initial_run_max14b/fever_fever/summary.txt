The FEVER dataset, short for Fact Extraction and VERification, is a large-scale dataset designed for the task of verifying textual claims against textual sources. It contains 185,445 claims generated by altering sentences extracted from Wikipedia, which are classified into three categories: Supported, Refuted, or NotEnoughInfo. The dataset is monolingual, focusing on English, and is intended for use in text classification tasks, particularly knowledge verification. The dataset is crowdsourced and includes multiple configurations, such as v1.0 and v2.0, with different data splits for training, validation, and testing. The v1.0 configuration includes a training set with 311,431 examples and various development and test sets, while v2.0 focuses on adversarial attacks with 2,384 validation examples. Additionally, the dataset includes a 'wiki_pages' configuration with 5,416,537 Wikipedia pages, providing a comprehensive source of evidence for claim verification. The dataset is licensed under cc-by-sa-3.0 and gpl-3.0, and it is intended to stimulate research in verifiable knowledge extraction, addressing the challenge of false information from unreliable sources. The dataset is available for download, with a total size of approximately 8.97 GB, including both the downloaded and generated data.
