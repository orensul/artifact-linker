The dataset is designed for the Financial Sentiment Analysis in the Wild (FiQA) challenge, focusing on aspect-based sentiment analysis in financial microblogs and news. It is structured into three subsets: train, valid, and test, containing 822, 117, and 234 examples respectively. The dataset includes six features: '_id', 'sentence', 'target', 'aspect', 'score', and 'type'. The '_id' is a unique identifier for each data point, 'sentence' contains the text to be analyzed, 'target' specifies the entity or subject of the sentiment, 'aspect' refers to the particular facet of the sentiment, 'score' is a numerical representation of the sentiment, and 'type' indicates whether the data point is a headline or a post. The dataset is available under the MIT license and can be accessed and downloaded via the FiQA Challenge homepage. It is intended for use in developing and evaluating models for sentiment analysis in the financial domain, providing a baseline for aspect-based sentiment analysis tasks. The total download size is 102,225 bytes, and the dataset size is 170,479 bytes.
