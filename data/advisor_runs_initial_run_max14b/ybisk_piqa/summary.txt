The 'Physical Interaction: Question Answering' (PIQA) dataset is designed to evaluate physical commonsense reasoning in natural language understanding systems. It contains multiple-choice questions that require selecting the most appropriate solution from two options, focusing on everyday situations with a preference for atypical solutions. The dataset is monolingual, with all text in English, and falls within the size category of 10,000 to 100,000 examples. It is divided into three splits: a training set with 16,113 examples, a validation set with 1,838 examples, and a test set with 3,084 examples. The dataset's total size is approximately 5.3 MB. Each data instance includes a 'goal' (the question), two possible solutions ('sol1' and 'sol2'), and a 'label' indicating the correct solution. The dataset is crowdsourced, with annotations derived from instructables.com, a platform providing instructions for various tasks using everyday materials. The intended use case is to challenge AI systems in understanding and reasoning about physical interactions, contributing to advancements in AI-completeness and robotics. The dataset is available under an unknown license, and its creation involved paid crowdsourcers.
