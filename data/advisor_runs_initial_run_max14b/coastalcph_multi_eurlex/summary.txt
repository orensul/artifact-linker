The MultiEURLEX dataset is a multilingual text classification dataset designed for multi-label and topic classification tasks. It encompasses a wide range of European languages, including Bulgarian, Czech, Danish, German, Greek, English, Spanish, Estonian, Finnish, French, Croatian, Hungarian, Italian, Lithuanian, Latvian, Maltese, Dutch, Polish, Portuguese, Romanian, Slovak, Slovenian, and Swedish. The dataset is structured into several configurations, each corresponding to a different language. Each configuration contains features such as 'celex_id', 'text', and 'labels', where 'labels' are multi-label class identifiers. The dataset is divided into training, validation, and test splits, with the number of examples varying across languages. The dataset size ranges from approximately 161 MB to 548 MB per language configuration, with a total download size of around 2.77 GB. The dataset is licensed under the Creative Commons Attribution-ShareAlike 4.0 International License (cc-by-sa-4.0). It is particularly useful for researchers and developers working on multilingual text classification models, providing a rich resource for training and evaluating algorithms in a variety of European languages.
