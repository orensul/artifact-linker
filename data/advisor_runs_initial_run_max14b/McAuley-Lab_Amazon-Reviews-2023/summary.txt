The dataset is a comprehensive collection of Amazon reviews from 2023, compiled by McAuley Lab. It encompasses a wide range of domains, including beauty, arts and crafts, electronics, gift cards, handmade products, industrial and scientific items, musical instruments, and toys and games. The dataset is structured into multiple configurations, each representing a different product category. Each configuration contains detailed features such as main category, title, average rating, number of ratings, features, description, price, images, videos, store, categories, details, parent ASIN, bought together items, subtitle, and author. The dataset is extensive, with sizes ranging from a few megabytes to several gigabytes, and includes millions of examples across different categories. The intended use cases for this dataset include recommendation systems, sentiment analysis, and market research. It provides rich metadata and user interaction data, making it suitable for developing and testing algorithms in the recommendation and review analysis domains. The dataset is available for download, with each category having its own set of data files.
