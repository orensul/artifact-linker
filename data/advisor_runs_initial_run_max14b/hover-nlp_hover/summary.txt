The HoVer dataset is a monolingual English dataset designed for text retrieval tasks, specifically focusing on fact-checking retrieval. It is expert-generated and falls under the size category of 10K to 100K instances. The dataset is original and licensed under cc-by-sa-4.0. It contains several features, including an integer 'id', a string 'uid', a 'claim' in string format, and 'supporting_facts' which is a list of key-value pairs. The 'label' feature is a class label indicating whether a claim is 'SUPPORTED' or 'NOT_SUPPORTED'. Additionally, it includes 'num_hops', an integer indicating the number of hops needed for retrieval, and 'hpqa_id', a string identifier. The dataset is divided into three splits: train, validation, and test, with 18,171, 4,000, and 4,000 examples respectively. The total download size is approximately 12.26 MB, and the dataset size is around 7.76 MB. The dataset is intended for use in developing and evaluating models for fact-checking and retrieval tasks, providing a structured format for claims and supporting evidence. The test set only includes 'id', 'uid', and 'claim', with labels represented by -1, indicating they are not available for this split.
