The dataset is designed for summarizing long documents, specifically scientific papers, and is adapted from a repository focused on long summarization. It is monolingual, containing English texts, and falls within the size category of 100K to 1M instances. The dataset is structured to support tasks such as summarization and text generation, with a focus on conditional text generation. It includes two configurations: 'document' and 'section', each containing features like 'article' and 'abstract', both of which are strings. The dataset is divided into three splits: train, validation, and test. The 'document' configuration has a training set with 119,924 examples, a validation set with 6,633 examples, and a test set with 6,658 examples. The 'section' configuration mirrors these splits. The dataset is compatible with the Transformers library's summarization script, requiring a specific line to be added for proper integration. The data is pre-tokenized, with text joined by spaces and paragraphs separated by newlines. The intended use cases include developing and evaluating models for abstractive summarization of long-form documents, particularly in the scientific domain.
