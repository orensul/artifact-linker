The DBpedia ontology classification dataset, known as DBpedia14, is a comprehensive dataset designed for text classification tasks, specifically topic classification. It is derived from the DBpedia 2014 dataset and consists of 14 distinct, non-overlapping classes. These classes include categories such as Company, Educational Institution, Artist, Athlete, and more, totaling 14 categories. The dataset is monolingual, primarily in English, although some entries may contain titles in other languages. The dataset is structured into two main splits: a training set with 560,000 samples and a test set with 70,000 samples, making it a large-scale dataset with a total size of over 200 million bytes. Each data instance includes three fields: a label indicating the class, a title, and the content of the document. The title and content are formatted as strings, with special characters properly escaped. The dataset is intended for use in developing and benchmarking text classification models, providing a robust resource for researchers and developers in the field of natural language processing.
