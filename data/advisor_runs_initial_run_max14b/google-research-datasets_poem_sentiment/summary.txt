The Gutenberg Poem Dataset is a sentiment classification dataset derived from poem verses available on Project Gutenberg. It is designed for tasks such as sentiment classification and style transfer in poetry. The dataset is monolingual, containing English text, and is licensed under the Creative Commons Attribution 4.0 International License. It consists of expert-generated annotations and includes a total of 1,101 examples, split into training (892 examples), validation (105 examples), and test (104 examples) sets. Each data instance comprises an 'id', 'verse_text', and a 'label' indicating the sentiment of the verse, which can be negative, positive, no impact, or mixed. The dataset is relatively small, falling within the 1K to 10K size category, and is stored in a format that includes integer and string data types. The dataset is intended for use in text classification tasks, specifically multi-class classification, and is available for download from a GitHub repository. It is part of a research effort to investigate societal biases in poetry composition systems, as documented in a related research paper. The dataset does not include any evaluation results or benchmark scores to prevent information leakage.
