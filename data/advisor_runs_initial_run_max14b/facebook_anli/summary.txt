The Adversarial Natural Language Inference (ANLI) dataset is a large-scale benchmark designed for evaluating natural language understanding models. It is collected through an iterative adversarial process involving both humans and models, making it more challenging than previous datasets like SNLI and MNLI. The dataset is monolingual, focusing on English, and is licensed under cc-by-nc-4.0. It is structured into three rounds, each containing separate train, development, and test splits. The dataset includes features such as 'uid', 'premise', 'hypothesis', 'label', and 'reason'. The 'label' feature is a classification label with possible values of 'entailment', 'neutral', and 'contradiction'. The dataset's size falls within the range of 100K to 1M examples, with a total disk usage of approximately 95.75 MB. The intended use cases for ANLI include tasks in text classification and natural language inference, providing a robust benchmark for testing the capabilities of language models in understanding and reasoning over text. The dataset is available in plain text format and can be accessed through its repository on GitHub. It is particularly useful for researchers and developers working on improving the robustness and accuracy of natural language processing models.
