The Real-world Annotated Few-shot Tasks (RAFT) dataset is a collection of English-language datasets designed for text classification tasks. It includes datasets from various domains such as medical, financial, legal, and social media, each associated with a binary or multiclass classification task. The dataset is monolingual, focusing on American English (en-US), and is intended to evaluate the performance of language models on real-world tasks. RAFT comprises original datasets and extensions from sources like ade_corpus_v2 and banking77. Each dataset provides only 50 labeled examples, making it suitable for few-shot learning scenarios. The dataset is structured into train and unlabeled test splits, with the train split containing 50 examples per dataset and the test split varying in size. The RAFT dataset is expert-generated and crowdsourced, with annotations provided by experts and contractors. It is licensed under specific terms and is available for use in text classification tasks, particularly multi-class classification. The dataset aims to provide a benchmark for evaluating NLP models on tasks with practical, real-world applications, without relying on contrived data sources. It is accessible through platforms like Hugging Face and has an associated leaderboard for performance evaluation.
