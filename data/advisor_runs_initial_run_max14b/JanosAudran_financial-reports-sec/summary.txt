The dataset comprises US public firm Annual Reports, specifically 10-K filings, sourced from the SEC's EDGAR database. It is designed for financial analysis and sentiment classification tasks, with applications in masked-language modeling and multi-class classification. The dataset is monolingual, containing English text, and is licensed under Apache 2.0. It is categorized into four configurations: large_lite, large_full, small_full, and small_lite, each varying in size and detail. The dataset's size ranges from 10M to 100M entries, with the large_full configuration being the most comprehensive, including additional metadata such as tickers, exchanges, and financial returns over different periods. Each entry in the dataset includes fields like CIK (Central Index Key), sentence, section, labels for sentiment (positive or negative), filing date, document ID, and sentence count. The dataset is split into training, validation, and test sets, with the large configurations containing millions of examples and the small configurations containing thousands. This dataset is intended for use in financial sentiment analysis, providing a rich resource for developing models that can interpret and classify financial text data.
